github-rules.md の「docs-shared（個人情報を除去した資料の共有）」の章に従って、
docs フォルダ内の資料から個人情報を除去したコピーを docs-shared フォルダに作成してください。
検出・除去はあなた（Claude）が責任を持って徹底的に行います。ユーザーの目視全確認は前提にしません。

手順の要点（詳細はgithub-rules.mdが正）：
1. 個人情報（氏名、住所、電話番号、メールアドレス、口座情報、会員番号・アカウント名等）を
   伏せ字（[氏名] [住所] 等）に置換したコピーを作る。docsの原本は変更しない。
   資料としての構成・数値・手順は保持する
2. 検出は必ず二段階で行う。
   一次：パターン検出＋文脈読解での走査
   二次：置換後の全文を最初から読み直し、人名らしい固有名詞・文脈から特定できる記述・
   　　　表やヘッダー等の見落としやすい場所を別視点で再点検する
3. 迷ったら除去する（安全側に倒す）。除去で資料価値が大きく損なわれる場合は
   そのファイルを共有対象から外して報告する
4. 「ファイルごとの除去件数・種類・迷って除去した項目・対象から外したファイル」の
   要約レポートを提示し、ユーザーのOKを待つ。OK前にCommit・Pushはしない
5. 漏れの疑いを消しきれないファイルは docs-shared に置かない
