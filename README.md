# 体育祭審判要項 スマホ配布サイト

第70回・那珂南校区体育祭（2026年10月4日開催）の審判要項を、当日スタッフがスマホでさっと確認できるように配布するための静的サイトです。

## これは何をするもの？

- 紙で配布する審判要項（文字が多く縮小印刷では読みにくい）を、スマホで見やすく確認できるようにするツールです
- 種目ごとの時刻・競技方法・審判の役割・コース割・配置図を表示します
- QRコードで配布し、当日その場での通信に頼らず開けるようにします（PWA対応でオフライン閲覧が可能）

## 使い方（当日スタッフ向け）

紙の審判要項に印刷されたQRコードを読み取ってアクセスしてください。

## データの更新について

種目データはExcel原本から生成しています。担当者名や時刻に変更があった場合は、Excel側を修正してデータを再生成すれば、サイトの表示に反映されます（詳しい手順はWORKLOG.mdを参照）。

## 公開範囲について

このリポジトリはGitHub Pagesでの公開・QRコード配布を目的として、Publicで運用しています。審判担当者の実名など個人情報が含まれる可能性がある点は承知のうえで運用しています。
